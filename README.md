# 桂养安心·旅居智管

面向广西旅居养老场景的智慧监管演示站点，包含老人端、养老机构端和主管部门监管端三类角色。

## 核心演示链路

1. 老人通过视频场景中的语音或文字描述需求，系统生成简短行动卡。
2. 行动卡可转化为带风险、责任单位和处置时限的求助事件。
3. 机构端完成人工复核、事件处置和服务台账回填。
4. 监管端查看人群动态、机构质量、风险预警与事件闭环情况。

## 公开版本说明

GitHub Pages 仅托管静态前端，不保存或公开 DeepSeek API 密钥。在线版本使用本地安全规则生成应急、维权和政务指引；摄像头画面与原始音视频不会上传。页面中的健康快筛和生理指标为非诊断性原型演示，不能替代医疗诊断。

如需启用 DeepSeek 对话，请在本地运行 `server.py`，并在本机单独配置 `DEEPSEEK_API_KEY`。密钥配置文件已被 `.gitignore` 排除。
