桂养安心·旅居智管 | 作品 v1

一、打开方式
1. 推荐双击“启动作品.bat”，站点会在 http://127.0.0.1:4173 打开，并安全接入 DeepSeek。
2. 本地服务会自动读取桌面的 deepseek.env.local，支持以下配置项：
   DEEPSEEK_BASE_URL=接口地址
   DEEPSEEK_MODEL=模型名
   DEEPSEEK_API_KEY=密钥
   密钥只由本地 server.py 读取，不会发送给网页、写入日志或打进站点代码。
3. 也可直接双击 index.html 离线查看；此时AI视频助手会自动使用本地应急规则，不会调用DeepSeek。
4. 站点使用浏览器本地存储保存演示操作，刷新页面不会丢失新增服务记录、求助事件和处置结果。
5. 登录页选择角色后使用对应演示账号：
   老人端：elder / 123456
   机构端：center / 123456
   监管端：admin / 123456

二、建议演示顺序
1. 老人端：点击“AI视频助手”，开启摄像头后直接说出问题；也可输入“我被多收了费用，应该找谁？”，查看DeepSeek生成的适老行动卡，再点击“生成求助事件”。
2. 机构端：重新登录 center，进入“预警处置”查看新事件，打开事件并保存处理结果；也可在“服务台账”新增服务记录。
3. 监管端：重新登录 admin，在“事件中心”查看事件状态，在“机构监管”查看机构质量，在“人群监测”查看数据新鲜度和风险构成。
4. 可用右上角通知查看待办，用户菜单中的“恢复初始数据”可还原演示数据。

三、作品边界
- AI视频对话会将浏览器语音识别后的文字发送给DeepSeek；摄像头画面和原始音视频不上传。输出用于风险筛查与办事指引，不作医学诊断，高风险仍需人工确认。
- “AI辅助状态筛查”中的生理指标为赛事原型演示结果，页面已明确标注；真实部署须接入经过验证的 rPPG/医疗设备算法并完成合规评估。
- DeepSeek不可用或直接双击index.html时，系统自动切换本地应急规则，保证120、110、12315、12345等关键指引可继续演示。
- 当前事件路由和联系电话用于竞赛原型，真实部署前需由广西主管部门核验属地责任清单并接入正式渠道。
- 机构端是业务闭环必需角色：机构负责生成服务记录、确认预警和回填结果；监管端负责趋势、督办和跨部门联动。

四、本轮新增：老年人情感与身心风险评估亮点
- 老人端新增“五维身心快筛”：肢体活动、言语沟通、视听能力、心理与情绪、日常生活能力。
- 结果保留来源、更新时间、置信度、可观察证据、缺项和照护计划；睡眠、食欲、跌倒、头晕、步态不稳、情绪低落等变化会进入风险提示。
- 机构端新增“身心风险复核队列”，支持查看逐项证据、填写人工复核备注并确认写回动态台账。
- 监管端新增聚合质量指标：五维字段完整率、人工复核及时率、证据可追溯率；不展示老人原始音视频。
- 采用缺项拒判、冲突转人工、高风险必须复核的规则，AI只负责采集与结构化，最终等级由确定性规则和工作人员确认。

五、主要文件
- index.html：离线入口与角色工作台容器
- styles.css：响应式界面与适老化样式
- PRODUCT.md：按 Impeccable 方法整理的产品上下文、用户与边界
- DESIGN.md：按 Impeccable 方法整理的视觉规则与审查清单
- data.js：脱敏演示数据
- app.js：登录、三端页面、动态台账、事件处置和本地交互
- server.py：静态站点服务与DeepSeek安全代理
- 启动作品.bat：一键启动本地服务
- assets/lucide.min.js：本地化图标资源
